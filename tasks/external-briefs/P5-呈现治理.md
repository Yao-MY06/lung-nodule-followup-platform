> ⚠️ **前置**：必须在已完成 P0 + P1 + P2 + P3 + P4 执行书的**同一目录**内继续（16 模块已构建通过）。

## 0. 前置补丁（校验项）

**根 pom.xml 的 `dependencyManagement` 必须含两条第三方版本**（当前版 P0 执行书已包含；若你的 replay 目录是用旧版 P0 执行书构建的，需补上，否则 P2 引 xxl-job-core / 本阶段引 minio 会因无版本声明构建失败；放在第三方区，版本用属性引用）：
```xml
<dependency>
    <groupId>com.xuxueli</groupId>
    <artifactId>xxl-job-core</artifactId>
    <version>${xxl-job.version}</version>
</dependency>
<dependency>
    <groupId>io.minio</groupId>
    <artifactId>minio</artifactId>
    <version>${minio.version}</version>
</dependency>
```
并在 `<properties>` 补（若 P0 执行书未含）：
```xml
<xxl-job.version>2.4.1</xxl-job.version>
<minio.version>8.5.7</minio.version>
```
> 说明：followup（P2 引 xxl-job-core）、file（本阶段引 minio）的子 POM 不写版本，靠这两条 BOM 声明兜底。这是与主仓对齐的必要修正。

## 1. 目标与边界

**目标**：统计驾驶舱 + 附件服务 + 服务治理与压测准备，满足验收：
- `mvn install` 全绿（18 个模块：P4 的 16 个 + statistics + file）
- statistics 指标口径单测 + 空快照不报错；file 白名单/大小/路径穿越防护单测
- gateway + Sentinel 依赖编译通过且**默认配置不影响启动**（控制台未启动照常运行）
- 熔断/限流/压测三套演示步骤文档 + JMeter 脚本就绪

**不在范围（P5b）**：statistics 换 Feign 真实拉取（本期 DemoStatsCollector 模拟数据）、Redis/Caffeine 缓存、file 真实 MinIO 运行验证。

**本阶段新增/修改**：
- 新增：`yiliao-statistics/**`、`yiliao-file/**`、`docker/init-sql/yiliao_stats.sql`、yiliao-api file 包、`tasks/P5-熔断与压测方案.md`、`tasks/jmeter/**`
- 修改：根 pom（modules +2 + BOM 补丁）、gateway pom（+sentinel starter）、gateway yml（+sentinel 段 +2 路由）

## 2. 硬约束（违反即返工）

1. P0~P4 全部硬约束继续有效。
2. **statistics 预聚合数据源本期用 DemoStatsCollector**（模拟数据）：毕设演示本就要求构造模拟数据（AGENTS.md 测试与验证节），P5b 换 Feign 真实拉取——取数走 `StatsCollector` 接口，换实现不改查询层。
3. **快照表物理删除重建**：stats 快照表 Mapper 用物理 `DELETE`（非 @TableLogic 逻辑删除）——每轮"删旧+批量插新"同一事务，逻辑删除会与唯一键冲突；`deleted` 列按全局表约定保留。
4. **file 无数据库**：不依赖 common-data；附件只走 MinIO 预签名 URL（限时访问，禁止永久直链）；对象键白名单 + 大小上限 + 路径穿越三层防护。
5. **Sentinel 默认不依赖控制台**：`eager=false` 懒加载 + `transport.dashboard` 保持注释——控制台未启动时网关照常路由与鉴权；限流响应统一为 `Result{code:11001}`（HTTP 429），替换默认裸 429 文本。
6. 压测脚本/文档是**论文证据素材**，口径为"单机相对对比"，不宣称绝对容量。

## 3. 已知陷阱（先记再写）

1. P0~P4 全部陷阱继续有效。
2. **statistics 无 Redis**：yml 排除 Redisson/Redis 自动装配（同 nodule 写法）。
3. **Sentinel 限流处理器（WebFlux）**：`WebFluxCallbackManager.setBlockHandler` 注册全局 BlockExceptionHandler，返回 JSON `Result{code:11001}`；starter 自带 `sentinel-spring-webflux-adapter` 自动把请求登记为 URL 资源，**无需**额外引 gateway 适配器（演示用普通 FlowRule）。
4. **XXL-Job 分片**（statistics 预聚合本期单分片即可，但保留分片接口）：2.4.1 用 `XxlJobHelper.getShardIndex()/getShardTotal()`。
5. **JMeter jmx 是 XML**：改并发只动 `ThreadGroup.num_threads`；命令行 `-o` 输出目录必须不存在或为空，`-l` jtl 不可复用；GUI 监听器影响结果，正式压测用 `-n`。
