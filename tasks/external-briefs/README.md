# external-briefs · 外部模型执行书（P0~P5 全套）

> 用途：把主仓 `F:\bc\yiliao` 各阶段的产出"反编译"为自包含执行书，交给另一个模型在**全新空目录**从零重放，
> 用于：① 比对评审（外部模型产出 vs 主仓 P0~P5，出差异清单与评分）；② 论文"AI 辅助开发方法论"素材。

## 执行书清单与依赖关系

| 文件 | 阶段 | 前置 | 交付物 | 完成后模块数 |
|---|---|---|---|---|
| `P0-工程底座.md` | P0 | 无 | 根 POM + 6 common + api 骨架 + docker 三件套 + .gitignore | 9 |
| `P1-接入层.md` | P1 | P0 | gateway + auth + JWT 实现 + AuthApi + auth 库 DDL | 11 |
| `P2-核心域.md` | P2 | P1 | patient + nodule + followup（表驱动规则引擎）+ 三库 DDL/种子 | 14 |
| `P3-消息闭环.md` | P3 | P2 | notification + 提醒派发/逾期失访 + 幂等三保险 + notify 库 DDL | 15 |
| `P4-AI能力.md` | P4 | P3 | ai 服务（抽取/解读/RAG/工具）+ 确认排期链路 + ai 库 DDL | 16 |
| `P5-呈现治理.md` | P5 | P4 | statistics + file + Sentinel 接入 + 熔断/压测方案 + JMeter | 18 |

**串行执行**：必须按 P0→P1→…→P5 顺序在**同一 replay 目录**（如 `F:\bc\yiliao-p0-replay`）内连续执行，
每份执行书承接前序阶段（不重复定义前序产物，只追加本阶段增量）。若只投喂单份，需先让其完成对应前置阶段。

## 使用方式

1. 新建空目录（**绝不**在 `F:\bc\yiliao` 内操作——主仓 P0~P5 已完成，会冲突）。
2. 把对应执行书**全文**投喂给目标模型（自包含，无需会话上下文）。
3. 每份执行书自带：硬约束 / 已知陷阱（项目实际踩过的坑）/ 逐字规格（版本、DDL、yml、常量、Prompt、错误码）/ 命令级验证表 / 输出要求。
4. 外部模型按输出要求汇报后，拿回做比对评审。

## 规格粒度说明

- **逐字锁定**（错不了）：版本三元组、BOM 清单、表名/列名/索引/种子数据、Redis key 格式、HTTP 头名、Topic 常量、
  错误码与文案、业务阈值（2mm/5 次/7 天/30 天/T-7/3/1）、正则、Prompt 模板、免责语文案、bizKey 格式。
- **行为级规格**（允许实现自由）：方法内部实现、javadoc 措辞、日志文案——但签名、参数、返回、异常行为必须对齐。
- **与主仓的已知差异**（比对评审时不计为外部模型错误）：
  - P2 执行书不含 P4 才实现的 nodule extract/confirm 端点与 ConfirmService（按阶段归位，主仓最终态含之）。
  - 主仓 `yiliao-ai` 的 `PatientTools` 类名/包路径等细节以执行书为准。
  - 种子 BCrypt 哈希、开发占位密钥等敏感值为真实主仓值（仅开发环境用途，随执行书分发属可接受范围，仓库本身也是学生项目本地库）。

## 比对评审维度（拿回产出后）

1. **版本一致性**：三元组/BOM/插件版本与主仓根 POM 逐字一致
2. **结构一致性**：模块树、包结构、类清单对齐
3. **契约一致性**：Feign 绝对路径、DTO record 字段、Topic/bizKey/Redis key 格式逐字一致
4. **行为一致性**：验证表中每条命令/单测可通过；关键行为（幂等三保险、规则表驱动、防重锁、脱敏出网、工具越权防护、免责语强制）有证据
5. **约束遵守**：硬约束/禁止事项无违反（无 Lombok、无硬编码间隔、无类级 @RequestMapping 等）

评分建议：5 个维度各 20 分，逐字锁定项不一致直接扣分（每项 -1~-5），行为不一致按严重度扣分；80 分以上视为"对齐"。

## 维护

- 主仓 P0~P5 产出变更时（如 P1b 菜单、P3b 宣教问卷、P4b Seata/PgVector、P5b Feign 拉取/缓存），**不回改**本套执行书——它们固化的是"阶段首版"基线；新增阶段产物另写执行书或记入差异清单。
- P0 执行书已含 xxl-job 2.4.1 / minio 8.5.7 两条 BOM（P3/P5 依赖，2026-08-24 补正）。
