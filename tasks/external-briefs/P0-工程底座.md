# P0 工程底座 · 外部模型执行书（自包含）

> 用途：交给另一个模型在**新的空目录**从零执行 P0（parent + 6 个 common + yiliao-api 骨架 + docker-compose）。
> ⚠️ 不要在现有 `F:\bc\yiliao` 仓库内操作（P0~P5 已完成，会冲突）；在全新目录（如 `F:\bc\yiliao-p0-replay`）执行。
> 你是专注执行的子代理：只做本文指派的事；有歧义先列出理解请求确认；不新增未授权依赖；完成后按"输出要求"报告。

---

## 1. 目标与边界

**目标**：Maven 单仓多模块骨架 + 中间件编排，满足验收：
- `mvn install` 全绿（9 个模块：parent + common 父 + 6 个 common + api）
- `docker compose config --quiet` 校验通过
- 7 个业务库建库 SQL 就绪

**不在范围**：任何业务服务（gateway/auth 等 P1 起）、JWT/安全实现、Spring AI/Redisson/RocketMQ 的使用代码（仅锁版本）、业务表 DDL。

## 2. 前置环境

- JDK 17+（本机若为 JDK 25，见 §4 陷阱 1）；Maven 3.9+；Docker + Compose v2（仅校验配置，不要求启动）。

## 3. 硬约束（违反即返工）

1. **版本锁定在根 POM**：子 POM 一律不写版本号。三元组：Spring Boot **3.4.5** + Spring Cloud **2023.0.3** + Spring Cloud Alibaba **2023.0.3.2**（官方兼容表交叠集，勿改动）。
2. **不引入 Lombok**（JDK 25 兼容未验证）：全部手写 getter/setter 或用 record。
3. `groupId=com.yiliao`，根 artifactId `yiliao`，版本 `1.0.0-SNAPSHOT`，打包 `pom`。
4. common 模块之间**只允许依赖 common-core**；api 只依赖 common-core + openfeign。
5. 所有 Java 源码 UTF-8，包根 `com.yiliao.*`。

## 4. 已知陷阱（先记再写）

1. **JDK 25 × Mockito/ByteBuddy**：surefire 必须配 `<argLine>-Dnet.bytebuddy.experimental=true</argLine>`。
2. **MyBatis-Plus 3.5.7**：`insert` 有单条/集合重载，测试 mock 时 `any()` 需显式 `any(Entity.class)`。
3. **record 返回体**：访问器是 `code()/data()`，不是 `getXxx()`。
4. **AutoConfiguration 注册**：Spring Boot 3 用 `src/main/resources/META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports`（一行一个全限定类名），不是 spring.factories。

## 5. 执行步骤（按序）

### 步骤 1：根 pom.xml

要点（缺一不可）：
- `<modules>`：yiliao-common、yiliao-api
- properties：`maven.compiler.release=17`、UTF-8；版本属性：boot 3.4.5 / sc 2023.0.3 / sca 2023.0.3.2 / spring-ai 1.0.0 / mybatis-plus 3.5.7 / redisson 3.37.0 / rocketmq-spring 2.3.1 / knife4j 4.5.0 / jjwt 0.12.6 / xxl-job 2.4.1 / minio 8.5.7
- `dependencyManagement` 以 import 方式引入：spring-boot-dependencies、spring-cloud-dependencies、spring-cloud-alibaba-dependencies、spring-ai-bom；再声明第三方：`com.baomidou:mybatis-plus-spring-boot3-starter`、`org.redisson:redisson-spring-boot-starter`、`org.apache.rocketmq:rocketmq-spring-boot-starter`、`com.github.xiaoymin:knife4j-openapi3-jakarta-spring-boot-starter`、jjwt-api/impl(runtime)/jackson(runtime)、`com.xuxueli:xxl-job-core`、`io.minio:minio`
- `dependencyManagement` 同时声明 7 个内部模块 GAV（yiliao-common-core/web/data/security/mq/feign + yiliao-api，version 用 `${project.version}`），保证子 POM 引用不写版本
- `pluginManagement`：maven-compiler-plugin 3.13.0（release 17）、maven-surefire-plugin 3.5.2（§4 陷阱 1 的 argLine）、spring-boot-maven-plugin ${boot.version}

### 步骤 2：yiliao-common（父 pom 打包 pom，modules 指向 6 个子模块）

每个子模块 = 一个 pom + 指定类。类规格（签名级，自行补实现与 javadoc）：

**2.1 yiliao-common-core**（依赖：仅 `jakarta.validation:jakarta.validation-api`；测试 junit-jupiter）
- `core.result.Result<T>`：record(code,msg,data)，静态 `ok()/ok(data)/fail(ErrorCode)/fail(code,msg)` + `isSuccess()`
- `core.error.ErrorCode`：接口 `int getCode()/String getMsg()/ErrorCode withMsg(String)`
- `core.error.CommonErrorCode`：枚举 0 成功/401 未认证/403 无权限/404 不存在/400 参数错误/500 系统繁忙；嵌套 record 实现自定义 msg
- `core.exception.BizException`：持有 ErrorCode，构造 `(ErrorCode)` 与 `(ErrorCode,String)`
- `core.page.PageQuery`：page=1/size=10（@Max(100)）/sortBy/sortOrder + `offset()`
- `core.page.PageResult<T>`：record(records,total,page,size) + `of()/empty()`
- `core.enums.BaseEnum`：接口 `getCode()/getDesc()`
- `core.constant.YiliaoConstants`：`CACHE_PREFIX="yiliao:"`、`LOCK_PREFIX`、`MQ_CONSUMED_PREFIX`、`TOKEN_BLACKLIST_PREFIX`、头常量 `HEADER_USER_ID="X-User-Id"/HEADER_USER_ROLES/HEADER_TRACE_ID`、角色常量 ADMIN/DOCTOR/NURSE/PATIENT

**2.2 yiliao-common-web**（依赖 core、starter-web、starter-validation、knife4j starter；测试 starter-test）
- `web.handler.GlobalExceptionHandler`（@RestControllerAdvice）：BizException→其码；MethodArgumentNotValidException→400+字段级信息拼接；NoResourceFoundException→404；兜底 Exception→500（日志记堆栈，msg 不外泄）
- `web.config.YiliaoWebAutoConfiguration`（@AutoConfiguration）：@Bean GlobalExceptionHandler + @Bean Jackson2ObjectMapperBuilderCustomizer（LocalDateTime `yyyy-MM-dd HH:mm:ss`、LocalDate `yyyy-MM-dd`，用 serializersByType/deserializersByType）
- 注册文件见 §4 陷阱 4

**2.3 yiliao-common-data**（依赖 core、MP starter、starter-data-redis、redisson starter）
- `data.entity.BaseEntity`：id(@TableId AUTO)/createTime(INSERT 填充)/updateTime(INSERT_UPDATE)/createBy/updateBy/@TableLogic deleted
- `data.fill.UserContextProvider`：接口 `Long currentUserId()`（解耦：data 不依赖 security）
- `data.fill.YiliaoMetaObjectHandler`：四字段严格填充，操作人取 provider（可 null）
- `data.config.YiliaoDataAutoConfiguration`：@Bean MybatisPlusInterceptor(PaginationInnerInterceptor MYSQL) + @Bean MetaObjectHandler（ObjectProvider 注入 UserContextProvider，可缺省）
- `data.page.PageResults`：`of(IPage<T>)` 与 `of(IPage<S>, Function)` 转 PageResult
- 注册文件同上

**2.4 yiliao-common-security**（依赖 core + spring-boot + jjwt 三件套）
- P0 仅骨架：`security.context.CurrentUser` record(userId,username,roles)+hasRole/isPatient；`security.context.SecurityContextHolder`（ThreadLocal set/get/clear/currentUserIdOrNull）
- **不实现** JWT（P1 红区任务）

**2.5 yiliao-common-mq**（依赖 core、jackson-databind、rocketmq starter、starter-data-redis）
- `mq.event.BaseEvent<T>`：record(eventId UUID,eventType,bizKey,source,occurredAt,payload) + 静态 `of(...)`
- `mq.constant.Topics`：6 个常量 YILIAO_ARCHIVE_CREATED/EXTRACT_CONFIRMED/PLAN_CREATED/REMIND_DUE/NODULE_PROGRESS/SYMPTOM_ALERT

**2.6 yiliao-common-feign**（依赖 core、starter-openfeign、jakarta.servlet-api(provided)）
- `feign.HeaderRelayInterceptor` implements RequestInterceptor：RequestContextHolder 取当前请求，透传 X-User-Id/X-User-Roles/X-Trace-Id（无请求上下文跳过）
- `feign.YiliaoFeignAutoConfiguration` + 注册文件

### 步骤 3：yiliao-api（契约骨架）

依赖：common-core + starter-openfeign。内容：
- `api.ai.dto.NoduleExtract`：record(location, noduleType /*SOLID/PART_SOLID/PURE_GG*/, maxDiameterMm, solidDiameterMm, count, signs List, impression)（BigDecimal）
- 其余仅 `package-info.java` 建包：api.auth / api.patient / api.nodule / api.followup / api.notify / api.file（各一句"契约 P1+ 实现"注释）

### 步骤 4：docker/

- `docker-compose.yml`：services = mysql:8.0（3306，root/yiliao123，挂 `./init-sql:/docker-entrypoint-initdb.d:ro`，utf8mb4，healthcheck）、redis:7-alpine（appendonly）、nacos/nacos-server:v2.3.2（standalone，8848/9848，healthcheck）、rocketmq-namesrv + rocketmq-broker（apache/rocketmq:5.2.0，broker 挂载 broker.conf）、minio/minio:latest（9000/9001，yiliao/yiliao123456）；命名 `name: yiliao`，容器名 yiliao-*；xxl-job/seata/sentinel 以注释占位（写明"按阶段启用"）
- `rocketmq/broker.conf`：集群/ASYNC_MASTER/ASYNC_FLUSH/autoCreateTopicEnable=true/brokerIP1=host.docker.internal
- `init-sql/01-databases.sql`：CREATE DATABASE IF NOT EXISTS yiliao_auth/patient/nodule/followup/notify/ai/stats（utf8mb4）
