# P2 核心域 · 外部模型执行书（自包含）

> 用途：交给另一个模型执行 P2（yiliao-patient + yiliao-nodule + yiliao-followup 随访引擎 + 三库 DDL）。
> ⚠️ **前置**：必须在已完成 P0 + P1 执行书的**同一目录**内继续（11 模块已构建通过）。
> ⚠️ 不要在现有 `F:\bc\yiliao` 仓库内操作（P0~P5 已完成，会冲突）。
> 你是专注执行的子代理：只做本文指派的事；有歧义先列出理解请求确认；不新增未授权依赖；完成后按"输出要求"报告。

---

## 1. 目标与边界

**目标**：核心业务三服务 + 表驱动随访规则引擎，满足验收：
- `mvn install` 全绿（14 个模块：P1 的 11 个 + patient + nodule + followup）
- 规则引擎单测：条件运算符/优先级/无命中报 22002 全绿
- 计划生成单测：铺点/截断/防重/上限保护全绿；对比单测：≥2mm 触发判定全绿
- 三库 DDL + followup 规则/模板种子（16 条决策规则 + 6 条模板）幂等可重跑

**不在范围**：MQ 事件发布消费（P3 接线，本阶段 followup 只写 `PlanEventPublisher` 的类骨架不强制发消息——**见步骤 5 决策**）；AI 抽取（P4，本阶段 confirm 链路**不实现**，只建表建端点占位）；Seata（P4）；患者全景时间轴聚合（P2b）。

> 与主仓的差异声明（执行时不必实现，主仓 P2 之后阶段补的）：nodule 的 `/exam/reports/{id}/extract` 与 `/confirm` 端点、ConfirmService 属 P4 范围；本执行书只要求 P2 原生范围（建档/登记/快照/对比/计划/工作台/症状上报骨架）。

## 2. 硬约束（违反即返工）

1. P0/P1 全部硬约束继续有效（版本三元组、子 POM 禁版本、禁 Lombok、Feign 绝对路径、实现类禁类级 @RequestMapping）。
2. **随访规则是数据不是代码**：随访间隔禁止在 Java 里写 if-else 硬编码——规则只存 `decision_rule` 表（cond_json），引擎只做条件求值与优先级选择。这是项目关键不变量，违反即返工。
3. **防重生成**：计划生成 = Redisson 锁（key=`yiliao:lock:plan:{patientId}`）+ `followup_plan` 唯一索引兜底；同一患者同一时刻只有一个进行中计划（status=1）。
4. **升级阈值**：结节增大或实性成分增加 ≥2mm（**含等号**）判进展——nodule 只算 Δ，升级策略归 followup，不越界。
5. PII：`id_card` AES-GCM 加密存储（32 字节 base64 密钥走配置）、展示脱敏（前 3 后 4）；`phone` 出参脱敏 `138****5678`。
6. 建档联动：patient 建档成功后 Feign 调 followup 生成计划，**失败不阻断建档**（catch 后记 autoPlanError）。

## 3. 已知陷阱（先记再写）

1. P0 的 4 条陷阱 + P1 的 5 条全部继续有效。
2. **MyBatis-Plus insert 重载**：测试 mock `insert(any())` 有歧义，必须 `insert(any(实体.class))`；且 mock insert 不回填自增 id，需要 id 时 `thenAnswer` 手动 set。
3. **Redisson tryLock 测试**：`RLock.tryLock(wait, lease, unit)` 是重载，mock 用 `tryLock(anyLong(), anyLong(), any(TimeUnit.class))`。
4. **生成列**：`followup_plan.active_flag` 是 MySQL 生成列（`GENERATED ALWAYS AS ... STORED`），实体**不要**映射该字段（只读不写），唯一键 `uk_patient_active(patient_id, active_flag)` 靠数据库保证。
5. **XXL-Job**：本阶段 followup 引 `xxl-job-core` 依赖 + `XxlJobConfig`（`@ConditionalOnProperty("yiliao.xxl-job.enabled")` 默认 false 不装配）；Job Handler 类本阶段**不写**（P3）。
6. nodule 服务无 Redis 依赖：yml 必须排除 Redisson/Redis 自动装配（见步骤 4.2），否则无 Redis 时启动失败。

```java
private static final Pattern OP_PATTERN = Pattern.compile("^(<=|>=|<|>)\\s*([0-9.]+)$");
private static final Pattern RANGE_PATTERN = Pattern.compile("^([0-9.]+)\\s*-\\s*([0-9.]+)$");

/** 全部条件项满足才命中；空条件视为命中（作为兜底规则）。 */
public static boolean matches(Map<String, Object> conditions, RuleInputDTO input)

private static boolean evalOne(String key, Object condValue, RuleInputDTO input) {
    return switch (key) {
        case "nodule_type" -> intEquals(condValue, input.noduleType());
        case "max_dia" -> numeric(input.maxDiaMm(), str(condValue));
        case "risk" -> boolEquals(condValue, boolFeature(input.riskFactor()));
        case "gene_positive" -> boolEquals(condValue, boolFeature(input.genePositive()));
        case "adjuvant" -> boolEquals(condValue, boolFeature(input.adjuvantTherapy()));
        case "stage_group" -> str(condValue) == null
                || str(condValue).equalsIgnoreCase(nullSafe(input.stageGroup()));
        // 未知条件键：保守不命中，避免规则语义静默漂移
        default -> false;
    };
}
```
  - `numeric(feature, expression)`：feature 或 expression 为 null → false；先 OP_PATTERN（`<=` `>=` `<` `>` + compareTo），再 RANGE_PATTERN 闭区间（`>=low && <=high`），最后纯数字相等
  - `boolEquals`：布尔特征缺省按 false（`Boolean.TRUE.equals`）

```java
/** 命中多条取 priority 最高（同优先级取 id 小者，保证确定性）；无命中抛 22002，禁止默认间隔兜底。 */
public DecisionRule match(Integer scene, RuleInputDTO input) {
    List<DecisionRule> rules = decisionRuleMapper.selectList(new LambdaQueryWrapper<DecisionRule>()
            .eq(DecisionRule::getScene, scene)
            .eq(DecisionRule::getStatus, 1));

    return rules.stream()
            .filter(rule -> evaluate(rule, input))
            .max(Comparator.comparingInt(DecisionRule::getPriority)
                    .thenComparing(Comparator.comparingLong(DecisionRule::getId).reversed()))
            .orElseThrow(() -> {
                log.warn("规则无命中 scene={} input={}", scene, input);
                return new BizException(FollowupErrorCode.RULE_NOT_FOUND);
            });
}
```

- **`engine.TaskDatesPlanner`**（`public final class` 私有构造，纯静态；全文即规格）：
```java
public static final int MAX_TASKS = 300;

public static List<LocalDate> plan(LocalDate start, int firstIntervalMonth, int repeatIntervalMonth,
                                   int totalYears) {
    if (repeatIntervalMonth <= 0) {
        throw new IllegalArgumentException("repeatIntervalMonth 必须 > 0");
    }
    LocalDate deadline = start.plusYears(totalYears);
    List<LocalDate> dates = new ArrayList<>();
    LocalDate first = start.plusMonths(firstIntervalMonth);
    if (first.isAfter(deadline)) {
        return dates;
    }
    dates.add(first);
    LocalDate cursor = first;
    while (dates.size() < MAX_TASKS) {
        LocalDate next = cursor.plusMonths(repeatIntervalMonth);
        if (next.isAfter(deadline)) {
            break;
        }
        dates.add(next);
        cursor = next;
    }
    return dates;
}
```
