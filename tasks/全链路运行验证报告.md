## 过程中发现并修复的缺陷（6 个，均已回写 AGENTS.md 已知陷阱）

1. **Redisson 排除类名错误**：3.37.0 是 `RedissonAutoConfigurationV2`，旧名排除无效致启动失败。
2. **Spring Cloud 兼容性校验器**：SC 2023.0.3 校验器拒绝 Boot 3.4.5（SCA 官方矩阵实际允许）——9 服务统一加 `spring.cloud.compatibility-verifier.enabled=false`。
3. **Feign 无负载均衡依赖**：`@FeignClient(name=...)` 无 Nacos 时需 loadbalancer——全部契约改为 `url = "${yiliao.feign.{service}-url:http://localhost:{port}}"` 可配直连（生产留空走注册中心）。
4. **编译缺 `-parameters`**：parent compiler 插件补 `<parameters>true</parameters>`，否则 `@RequestParam` 绑定失败。
5. **rocketmq 配置缩进错误**：误置于 `spring.rocketmq`，应为根级 `rocketmq:`；且 rocketmq-spring 2.3.1 在 Boot 3.4 下 RocketMQTemplate 自动装配失效 → followup 手工装配 DefaultMQProducer+Template（注意 destroyMethod 签名问题）。
6. **SNAPSHOT 陈旧 jar**：本地仓库缓存旧版 common-core/api/data 导致运行期 NoSuchMethodError/ClassNotFound——增量 install 不可靠，接口变更后必须重装对应模块。

另：Git Bash curl 中文按 GBK 发送导致 JSON UTF-8 解析失败——测试用 UTF-8 文件体 `--data-binary`。
