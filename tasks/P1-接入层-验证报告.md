## 安全审查要点（红区自查，供人工复核）

1. **密钥**：JWT secret 在 application.yml 仅开发占位（`dev-only-secret-...`），生产由 Nacos/环境变量覆盖；`JwtTokenService` 构造期强制 ≥32 字节。
2. **密码**：仅存 BCrypt（强度 10）；任何接口不返回 password 字段（UserInfoDTO/LoginResponse 均不含）；日志不打印明文密码。
3. **防枚举**：账号不存在与密码错误统一 10001；失败计数 Redis key `yiliao:auth:fail:{username}`，5 次/10 分钟锁定。
4. **黑名单**：注销把 access+refresh 的 jti 拉黑，TTL=剩余有效期；gateway 与 auth 用**同一个** `JwtTokenService`（common-security）与同一个 key 前缀常量，消除双实现漂移。
5. **内部接口**：`/api/*/internal/**` 网关直接 404，不暴露服务间契约。
6. **fail-open 取舍**：gateway Redis 故障时放行（黑名单是少数场景，可用性优先）——specs/modules/gateway.md §5 已记录该决策，有 ERROR 告警观测。
