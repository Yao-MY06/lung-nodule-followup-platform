## 目标与边界

**目标**

1. `yiliao-auth`（8081）：登录（BCrypt 校验 + 失败锁定）、Token 签发/刷新/注销（JWT access 2h / refresh 7d + Redis 黑名单）、`/me`、AuthApi Feign 实现。
2. `yiliao-gateway`（8080）：路由表、JWT 校验全局过滤器（白名单/黑名单/透传 X-User-*）、CORS。
3. yiliao_auth 库 DDL + 种子数据（admin/doctor/nurse/patient 角色 + 管理员账号）。
4. 单元测试：JWT 签发/解析/过期、登录成功/密码错/锁定/停用、网关过滤器放行与拦截。

**不在范围内**

- 菜单树接口、用户 CRUD 管理界面（P1b）；Sentinel 限流规则（P5）；患者端数据权限（P2 随业务落地）；中间件启动验证（docker 挂起中，运行链路验证顺延）。

**受影响区域**

- 新增：`yiliao-auth/**`、`yiliao-gateway/**`、`yiliao-api` AuthApi、`docker/init-sql/yiliao_auth.sql`
- 修改：根 `pom.xml`（modules 列表）
