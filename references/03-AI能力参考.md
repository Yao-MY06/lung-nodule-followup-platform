## 关键设计对照（P4 实现前必读）

1. yu-ai-agent 的 RAG 管道顺序：加载 → 切分（TokenTextSplitter）→ Embedding → VectorStore → 检索增强 Advisor。我们 specs 的差异点：**混合检索（BM25+向量 RRF）+ Rerank** 是超出其实现的深度项。
2. Tool Calling：yu-ai-agent 用 `@Tool` 注解注册普通方法——与我们 F4"工具=普通 Java 方法+服务端强制当前患者身份"的设计一致，权限控制是我们额外加的。
3. SSE：`Flux<ChatResponse>` + `text/event-stream`；会话记忆 Redis——specs/modules/ai.md §4.8 已按此设计。
4. 结构化抽取：官方示例的 BeanOutputConverter + JSON Schema 约束——`NoduleExtract` DTO 直接套用（specs/modules/ai.md §3）。
